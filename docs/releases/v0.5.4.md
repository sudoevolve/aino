# v0.5.4

本版落实 [2026-11-23 工程审查](../reviews/20-codebase-audit-2026-11-23.md) 中的正确性修复、可落地性能优化与冗余清理。保持单头文件、CPU 光栅化和事件驱动调度；核心没有新增第三方构建依赖。

## 源码迁移

本版移除历史接口，**存在源码不兼容变更**，不提供转发别名或旧接口开关。

| 已移除 | 当前写法 |
| --- | --- |
| `Window(w, h, title)` | `Window(WindowConfig{w, h, title})`，其它选项在配置结构中设置 |
| `Theme::macos_light/macos_dark` | `Theme::light/dark` |
| Theme `background/foreground` | `window_bg/label` |
| Theme `card/card_foreground` | `card_bg/label` |
| Theme `popover/popover_foreground` | `popover_bg/label` |
| Theme `primary/primary_foreground` | `tint/tint_foreground`，强调色用 `set_tint()` |
| Theme `secondary/secondary_foreground` | `fill/label` |
| Theme `muted/muted_foreground`、`accent/accent_foreground` | `fill3/label2`、`fill3/label` |
| Theme `destructive/destructive_foreground` | `red/on_red` |
| Theme `border/input/ring` | `separator/input_border/focus_ring` |
| `control_h_mini/control_h_sm/control_h/control_h_lg/control_h_xl` | `size_h[0..4]` |
| `Style::text_color/fill` | `Style::color/background` |
| `aino::icons::*` 字符图标常量 | `Ui::system_icon(SystemIcon::..., box, color)`；自定义字符直接由应用提供 |
| `Rect::pad`、`Ui::card` | `Rect::inset`、`Ui::panel` |
| 隐式 `Ui::row/column/push_padding/pop_padding/begin_group/end_group` | 显式 `vbox/hbox` 返回的 `Stack` |
| `begin_scroll/end_scroll/scroll_y/scroll_to` | `auto sc = ui.scroll(...)`、`sc.y()/to()`；作用域外用 `scroll_offset(box)` |
| `ScrollScope` 移动赋值 | 移动构造；作用域按嵌套顺序关闭 |
| `drawer(..., side, box, ...)` | `drawer(..., box, ...)`，位置由 box 决定 |
| `Window::set_clipboard` | `try_set_clipboard()`，检查成功再删除原选区 |
| SSH Engine 可写传输引用及路径/指纹引用查询 | `transfer_snapshot()/cwd_snapshot()/fingerprint_snapshot()` 值快照；不暴露原生句柄 |
| 明文/XOR 密码解码和自动迁移 | 重新输入并使用系统凭据保存；未替换的记录保留并显示提示 |
| Windows ANSI／混合编码文字兜底 | 文本 API 统一 UTF-8，非法序列使用替换字符；外部编码由调用方转换 |

`Style::primary()/secondary()/destructive()` 是控件变体，`Stack::fill()` 是取剩余布局区域，它们具有独立行为并继续使用。当前 Wiki、示例与编译夹具仅使用当前接口。

## 修复与优化

| 审查编号 | 结果 |
| --- | --- |
| H01、M01 | 测量隔离输入与控件状态副本；已聚焦编辑器禁用后撤销焦点，阻止键盘修改 |
| H02 | POSIX 从 TCP 到握手、认证均以非阻塞调用和 poll 等待，避免本库及依赖阻塞路径的 fd_set 限制 |
| H03、M12 | 发现实际 Ninja/CMake，检测本机 MSVC 包含前缀，恢复头文件依赖记录；构建辅助入口默认并行度为 2 |
| M02、M03 | DECCKM 独立于备用屏；每格保存最多四个组合码点，绘制与复制使用同一编码路径 |
| M04 | JSON 跳过值识别字符串、转义、嵌套和数字；不完整/未知字段配置只读；外部修改后拒绝覆盖 |
| M05 | Windows 字体、配置、主机记录统一使用 UTF-8 路径转换 |
| M06、M07 | Cocoa 尊重 high_dpi 设置，检查字符串创建失败后再使用和释放 |
| M08 | DNS 独立有界任务不持有 Engine 或窗口；取消会话不等待系统解析完成 |
| M09 | Win32/X11/Cocoa 背板限制 16,777,216 像素、单边 16,384，新资源成功后替换；图片/图标异常路径使用 RAII；图标掩膜按 8 MiB 和 512 项限制 |
| M10 | 配置和凭据操作移到可 join 的单个后台任务；未改密码复用现有凭据；提交成功后清旧凭据，失败保留表单和模型 |
| M11 | 发布工作流自动启动隔离本地 SSH 服务，检查协议、文件内容、取消、错误和提交后的状态 |
| M13 | X11/Wayland 异步剪贴板接入主循环；输入目标、内容或选区变化时丢弃迟到结果；终端粘贴使用弱引用 |
| L01–L03 | 清除无读字段、未调用解码器、重复编码和失效测试元数据；文字旋转文档标明后端限制；番茄钟底卡保留 22 逻辑单位下边距 |

性能改动还包括：光标命中按一次布局生成位置，替代逐前缀测量；终端滚动旋转行容器；缓存预算超限后一次排序淘汰，替代反复全表查找；每个 SSH 会话复用一个磁盘线程，在文件读写和同步期间继续服务终端。

Windows Release 的 GDI 预热单次样本（字号 13、字重 400、ASCII，位置数组逐项相同）：

| 字符数 | 一次布局 | 逐前缀测量参考实现 |
| --- | --- | --- |
| 1,000 | 92 µs | 38,346 µs |
| 10,000 | 246 µs | 1,514,028 µs |

这是光标位置计算的局部对照，不是整帧延迟或应用 CPU 收益承诺。默认 Gallery 按钮页在后台桌面静置 5 秒，
进程单核口径 CPU 样本为 0.0%，RSS 约 25.3 MiB。主动交互 CPU 脚本因桌面的 Backstop Window 遮挡而没有有效样本，
未把该项记为通过；实际交互功能另有 19 项实窗检查。

代价与边界：组合字符单元增加固定内存，超过四个组合码点的部分不保留；尚无完整 grapheme/ZWJ shaping。测量按访问复制状态，复杂文本布局的测量有复制成本。后台磁盘操作无法强制取消系统文件 I/O，退出会等待其完成。凭据服务等待不会冻结界面，但退出仍须等待系统事务返回。

未加入全文 revision API、损伤绘制、图标子进程默认启用、无障碍、GPU 或新平台；这些是需独立设计和收益证据的建议，不属于本次修复。撤销历史、字体与后备缓冲仍按各自作用域预算，不宣称进程总内存有统一上限。

## 发布验证

- Windows：MSVC 19.51、Windows SDK 10.0.26100、Release `/MT`，六个示例编译通过，CTest 38 项通过；实际 Gallery 交互 19 项通过。
- Linux：Ubuntu 24.04 / GCC 13.3 / Xvfb，六个示例编译通过，CTest 20 项通过。延迟 120ms 的 X11 选区 owner 场景中，其他窗口继续绘制。
- SSH：隔离回环服务器使用 Python 3.14 / Paramiko 4.0.0。协议及实传 28 项，另验静默对端握手取消 2 项；Windows 再验客户端及传输 110 项。POSIX 使用高于 1088 的 socket 描述符。
- Linux Terminal 使用 AddressSanitizer + UndefinedBehaviorSanitizer，组合字符、极端 CSI、备用屏和选择复制检查通过。
- MSVC Ninja 的 Gallery 对象依赖记录包含 `../../aino.hpp`；最终增量构建正确报告无需重编。构建成功不再代替头依赖核对。
- 实际截图：番茄钟深浅主题 × 880×600 / 720×520 × 144 / 192 DPI；SSH 深浅主题 × 1320×820 / 980×600 × 96 / 144 DPI，布局与实际文字像素检查通过。
- 网站文档打包通过。macOS 与纯 Wayland 由发布候选提交的 GitHub 工作流执行原生后端验收，完成链接补在 GitHub 发布说明中。

本机最初使用发行版 Paramiko 2.12.0 时与系统 libssh2 1.11.0 的组合出现 MAC 校验失败；换用发行流程固定的 Paramiko 4.0.0 后通过。没有为旧测试服务器增加算法降级分支；这组结果不代表所有 SSH 服务端组合都已验收。

现存编译警告：GCC 对 calendar 日期格式化有截断的保守告警，MSVC 的一处旧交互夹具有 int→float 告警；本版未据此宣称零警告。系统 IME、真实混合 DPI 多屏、Keychain/libsecret 解锁交互、慢网断线及提交回复丢失仍需专门环境验收。
