## 本轮实际运行范围

- Windows：MinGW Release 构建，包含可选 SSH 示例和 CTest 探针；原生窗口测试使用当前桌面。
- Windows 多窗口：先增加同线程 sibling 关闭案例并复现失败，再移除 `WM_CLOSE` 中的线程级退出消息；测试同时保留宿主显式退出消息检查。
- Linux：在现有 WSL Ubuntu 中独立编译、运行 `ssh_files_probe`，覆盖文件错误、符号链接及 3 GiB 稀疏文件；没有验证 X11 窗口、系统输入法或剪贴板。
- macOS：没有原生运行环境；本轮修改不能记为 macOS 运行通过。
- GitHub Actions：已配置三平台 push/PR 回归；本地提交没有触发远端运行，不把配置存在写成 CI 已通过。
- SSH 依赖：修正本地 WinCNG 构建选项，启用 ECDH 后对实际 OpenSSH 10.2 服务器握手成功；未提交账号密码，未完成登录或传输验收。CTest 增加不联网的 `ssh_crypto` 算法能力检查。
- 测试隔离：曾因只设置 USERPROFILE 导致 SSH 界面测试覆盖实际用户配置，详见 [13 批次 12](13-project-review.md)。现改为显式 AINO_SSH_HOME，并在任何写入前验证路径；前后文件哈希确认修复后的测试未改动现有用户文件。历史被覆盖内容尚未恢复。

最终全量构建及测试结果记录在 [项目审查](13-project-review.md) 的批次表后，避免混用修复前的二进制结果。

## 原生平台验收顺序

每项先增加可复现的检查，再实现并在目标平台运行。不要通过禁用功能、清除状态或扩大裁剪区规避失败。

| 顺序 | 后续批次 | 最小验收条件 |
| --- | --- | --- |
| 1 | X11 剪贴板闭环 | 同进程双窗口及跨进程 UTF-8 复制/粘贴；处理所有权变化、目标格式、不支持的目标与超时；等待期间继续处理窗口事件；覆盖大内容分块传输边界 |
| 2 | Cocoa 事件和生命周期 | 主线程管理 AppKit 窗口；原生关闭能退出对应循环；同线程双窗口互不误关；尺寸、失焦、修饰键和 Retina 坐标一致；绘制与输入法均在原生环境检查 |
| 3 | Cocoa 剪贴板及空闲调度 | 系统剪贴板 UTF-8 往返；事件等待可由输入、后台更新、后台关闭和光标截止时间唤醒；测量实际空闲 CPU 及唤醒次数 |
| 4 | 通用键盘焦点 | Tab/Shift-Tab 顺序、禁用项跳过、滚动区可见性、Enter/Space 按钮激活；浮层输入隔离和关闭后焦点恢复；三平台原生输入复核 |
| 5 | 系统无障碍 | 明确角色、标签、值、焦点与动作模型，再逐平台接入；用对应系统辅助技术实际导航和操作 |

布局或页面外观发生变化时，仍遵循仓库 `AGENTS.md`：检查深浅主题、默认/最小窗口、
文字实际绘制边界和不同 DPI，并更新 README 引用的实际截图。

## SSH/SFTP 功能边界

网络示例的完整性与窗口后端分开验收。

| 项目 | 当前状态 | 后续验收 |
| --- | --- | --- |
| 私钥与主机校验 | 私钥路径/口令参数已修正；主机记录使用 RAII，读取错误、不匹配及首次保存失败均拒绝信任 | 真实服务器验证无口令/加密私钥、错误口令、主机指纹变更和重新连接 |
| 配置与错误反馈 | 同目录临时文件和原子替换；失败保留旧文件、草稿和模型；离线界面探针覆盖失败与重试 | 在真实用户目录和受限权限下复核；不承诺多进程配置合并或完整断电恢复 |
| 凭据存储 | 密码仍是可逆混淆 | 单独设计系统凭据存储和已有配置迁移；不得把混淆描述成加密保险箱 |
| 大文件 | 使用 64 位文件长度，3 GiB 稀疏文件检查通过 | 真实超过 2 GiB 上传/下载，校验内容和进度；本地长度检查不等于完成网络传输 |
| 传输与取消 | 有后台单文件传输、进度和取消；离线探针不连接服务器 | 运行可选本地服务器测试，检查中断、超时、取消后的部分文件与资源清理 |
| 目录及队列 | 尚无递归目录传输、传输队列和断点续传；上传入口仍有本地目录/唯一文件限制 | 按独立功能批次实现并补充服务端测试，不能仅用文案声称支持 |

本地服务端测试入口和独立测试目录的设置方法见 [01 的 SSH 部分](01-quickstart.md)。
普通 CTest 中的 `ssh_ui` 是离线界面测试；只有显式运行 `--local-transfer <端口>` 才会连接本地服务器。
