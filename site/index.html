hello.cppC++17
#define AINO_IMPLEMENTATION
#include "aino.hpp"

int main() {
    aino::Window win(880, 560, "Hello aino");
    if (!win.ok()) return 1;

    win.run([](aino::Ui& ui) {
        ui.heading("Hello, aino",
                   {28, 28, 300, 40});
    });
}

是否需要 GPU 或第三方 UI 框架？

核心通过 CPU 光栅化，并使用系统窗口、字体和绘图接口；不需要 GPU 图形 API 或第三方 UI 框架。Linux 的字体和图像功能使用系统运行库，可选 SSH 示例使用 libssh2。具体要求见构建说明。

空闲时，CPU 仍会持续绘制吗？

窗口在无事件时阻塞等待，后台状态变化后主动唤醒。光标闪烁、动画和持续播放仍需要更新，实际 CPU 开销随场景变化。缓存预算和采样方法见性能与资源。

三个平台的支持范围一样吗？

Windows、macOS 和 Linux 原生后端已存在，Linux 使用 X11 / XWayland。输入法、多显示器、系统互通与无障碍能力仍有不同边界，接入前请查看平台能力矩阵。

Wiki 教程在哪里维护？

正文直接读取仓库 docs/wiki/ 中的 Markdown，目录来自教程索引。阅读页可通过“查看 Markdown”回到原文件。工程审查记录独立放在 docs/reviews/。

如何参与项目？

欢迎反馈可复现的问题、完善教程或贡献代码。开发前请阅读开发约定。项目以 Apache-2.0 协议开源。
